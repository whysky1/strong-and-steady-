FÄRDIGT VERCEL-PAKET

API-nyckeln finns INTE i paketet.

Efter deployment:
Vercel -> projektet -> Settings -> Environment Variables
Name: OPENAI_API_KEY
Value: din OpenAI API-nyckel
Välj Production (gärna Preview + Development också) -> Save -> Redeploy.

AI-rutan uppskattar KH från naturlig text. Den ger inte insulindoser.
